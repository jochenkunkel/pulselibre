## End-to-end status

- **Envelope/record parser:** implemented for standard definitions, developer-field lengths, normal and compressed timestamps, monitoring `timestamp_16`, unknown fields and bounded diagnostics. Header and file CRC are validated before record parsing. Existing unit tests cover malformed/truncated bytes, sentinels, endian order, compressed timestamps, limits, and repeat decode.
- **Production observations:** only fields in the decoder's primary `Metric` mapping enter canonical FIT observations. SpO₂, stress and respiration candidates are separate, labeled untrusted, and may lack a measurement timestamp.
- **SQLite:** `FitObservationCommitter` writes provenance and active FIT generations transactionally. A synthetic API-35 instrumentation test verifies a real backfill to SQLite, a repeated import, one stored observation/provenance/source, foreign-key integrity, and rollback/retry after an injected commit failure. Re-decoding a source with a changed decoder version is not yet a fully demonstrated path: legacy source/provenance rows require exact version equality, and new canonical generations are not implicitly activated. This must be resolved and tested before expanding the production mapping.
- **Scientific analysis:** `UnifiedMeasurements` can aggregate active FIT-generation rows by origin/metric/unit. That generic aggregation is not a validated metric-specific method. Existing FIT charting is heart-rate-only.
- **Dashboard:** the FIT history card is heart-rate-only. Live event fields for steps, calories, SpO₂, stress, and respiration do not establish historical FIT support.
- **Original-file validation:** the five local S10 candidate files all passed FIT header and file CRC checks and were run through the Kotlin decoder in a temporary local-only test (test removed after execution; no raw values, timestamps, hashes, or source files were added to Git). Aggregate output: 439 decoder-counted data records, 316 heart-rate observations, 423 SpO₂ candidates, 455 respiration candidates, 455 stress candidates, 444 unknown Global 233 field-2 occurrences; 23 respiration candidates outside 1–100 and all 455 stress candidates timestamp-less. These are decoder outputs, not SQLite import counts. The files are distinct from the 31 S25 originals; those originals are not present in this checkout.
