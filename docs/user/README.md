# PulsLibre – Hilfe für Anwenderinnen und Anwender

PulsLibre ist eine **lokale, offline arbeitende** App für das Garmin-CIRQA-Armband: keine Cloud, kein Konto, keine Internetberechtigung, keine Diagnosen.

## Kurzstart
1. App öffnen und die angeforderten Berechtigungen („Geräte in der Nähe“, Benachrichtigungen) erlauben.
2. Unter **Gerät** prüfen, ob das Armband als „Verbunden“ erscheint und wann der letzte Empfang war.
3. Unter **Einstellungen** (Oberarm-Symbol oben rechts) Profil und optional ein eigenes **Schrittziel** eintragen.
4. **Übersicht** zeigt die aktuellen Werte, **Tag im Überblick** einen ganzen Tag, **Verlauf** und **Analysen** längere Zeiträume.

Die Abbildungen im Handbuch sind Emulator-Aufnahmen mit künstlichen Demo-Daten. Echte Gesundheitsdaten gehören nicht in dieses Repository.
