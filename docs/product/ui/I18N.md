# Mehrsprachigkeit (i18n) – Stand und Regeln

Sprachen: Deutsch, English, Français, Español. Standard: **Systemsprache**; Auswahl in den Einstellungen („Sprache“). Für jede andere Systemsprache gilt `values/` (Englisch) als Rückfall.

## Technik
- `AppLanguage`/`AppLanguageSettings`: Die Auswahl wird gespeichert; jede Activity setzt sie in `attachBaseContext` (`AppLanguageSettings.wrap`) um, die sichtbare Activity wird nach einer Änderung neu aufgebaut. Das ist deterministisch und unabhängig vom asynchronen System-Dienst für App-Sprachen. Bei „Systemsprache“ bleibt der Kontext unverändert; dann gilt auch die Android-13-Sprachauswahl pro App (`locales_config.xml` meldet de, en, fr, es). Der Dauerdienst (`CirqaContinuousRecordingService`) wrappt seinen Kontext ebenfalls in `attachBaseContext`; seine Benachrichtigung folgt damit der gewählten App-Sprache (Stand 24.11.2026 im Code geprüft).
- Texte stehen in `res/values/strings.xml` (Englisch), `values-de`, `values-fr`, `values-es`. Zugriff: `context.getString(R.string.…)` bzw. `getString(R.string.x, arg)`; keine Satzbau-Verkettung, Platzhalter nummeriert (`%1$s`).
- `StringResourcesParityTest` (Unit-Test) erzwingt gleiche Schlüssel, gleiche Platzhalter und keine leeren Texte in allen vier Sprachen.
- Sprachnamen stehen immer in der eigenen Sprache.

## Umstellung
Bisher sind **nur** die Spracheinstellung selbst übersetzt. Die übrigen Oberflächentexte (rund 2250 Zeilen mit deutschen Literalen) werden Seite für Seite umgestellt: Einstellungen, Übersicht, Verlauf, Gerät, Daten, Dialoge, Analysen, Handbuch. Bis dahin erscheinen noch nicht umgestellte Texte auf Deutsch.

## Qualität
Übersetzungen sind Entwürfe von Claude Code. Medizinisch/rechtlich heikle Texte (Hinweise, Grenzwerte, Datenschutz) werden gekennzeichnet und vor Freigabe vom Projektinhaber geprüft. Keine Messwerte, Diagnosen oder Empfehlungen werden sinngemäß verändert.
