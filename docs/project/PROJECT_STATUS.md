**Haupt-IDE ist VSCodium („Codium“).** Claude Code und OpenAI Codex sind zwei alternative API-/Agenten-Zugänge **derselben IDE**, von denen **immer nur einer aktiv ist**. - Sicherheitsregel: Solange das Repository öffentlich ist, laufen Pull Requests und Fork-Code **nicht** auf einem Self-hosted Runner. LOCAL wird erst über die Repository-Variable `PULSELIBRE_LOCAL_RUNNER_ENABLED=true` aktiviert; bis dahin erfolgt ein sichtbarer CLOUD-Fallback.
- Der Self-hosted Runner (Label `pulselibre`) ist **vorbereitet, aber nicht registriert**. Installations- und Wartungsskripte: `tools/runner/`. Dokumentation: [ci/HYBRID_CI.md](../quality/ci/HYBRID_CI.md).
- Die Repository-Sichtbarkeit wurde **nicht** geändert. Signaturschlüssel und Secrets wurden **nicht** verändert.
- Lokale Testläufe (QUICK/FULL), Cloud-Läufe und der Signaturvergleich sind in [CI_TEST_STRATEGY.md](../quality/CI_TEST_STRATEGY.md) mit tatsächlichem Ergebnis dokumentiert; nicht ausführbare Tests bleiben offen.
